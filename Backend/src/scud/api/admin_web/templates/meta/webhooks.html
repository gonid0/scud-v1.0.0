Payload-формат

{
  "event_type": "passage_event",
  "webhook_id": "...",
  "data": {
    "event_id": "uuid",
    "reader_id": "hex",
    "key_id": "hex",
    "permit_id": "uuid",
    "user_id": 42,
    "phone_pubkey": "hex",
    "passed_at": "2026-05-19T10:11:12+00:00",
    "direction": 1,
    "session_seq": 7
  }
}

Если секрет задан — заголовок: X-SCUD-Signature: sha256=<hexdigest>. Hex = HMAC-SHA256(secret, raw_body). Сверьте на приёмнике для anti-spoof.
